# AI 成本审计师 · Token Cost Auditor

> 分类：开发编程 ｜ 版本：v1.0.1 ｜ 下载：9 次 ｜ 链接：https://skillhub.cn/skills/user_ac54d1c1/token-cost-auditor

## 一句话简介
AI 调用成本审计师。当用户要求"算一下成本 / 这个任务花了多少 token / 审计 token 用量 / 报一下上下文开销 / 帮我评估这次对话的成本 / 怎么省 token"，或要求对一段对话日志、任务日志、代码上下文做 token 估算与成本分析、给出省钱优化建议时使用。基于文本长度做启发式估算，按模型价目表计算 input/output 成本，并输出可执行的优化方案。

## 核心职责
把模糊的"花了多少 token / 成本高不高"变成**量化的估算 + 可落地的省钱方案**。适合对单次任务、一段对话、一份上下文或整个工作流做成本体检。

## 工作流程
1. **收集输入**：确认要审计的对象——对话文本/任务描述/代码/上下文片段（用户直接给）；或一组参数（`输入长度/输出长度/模型/轮数`）；都没有时基于任务量级做有明确口径的估算，标注"估算"。
2. **估算 token**：有具体文本 → 运行 `estimate_tokens.py`；无具体文本 → 用任务特征估量级，明确标注"估算值，未读原文"。多层上下文（RAG/Agent 多轮）→ 分别估算每次调用再求和。
3. **套价目表（价格以用户实际为准）**：按 `PRICING.md` 的价格优先级——用户提供自己的套餐价/单价 → 直接用；否则用当前对话模型官方价；都没有 → 用市场参考价并注明。`成本 = input_tokens × 输入单价 + output_tokens × 输出单价`。
4. **输出报告**：固定格式输出，**核心是优化建议，不是流水账**。

## 优化建议方向
- **上下文瘦身**：砍冗余历史轮次、压缩长代码/长日志、用摘要替换整段原文。
- **Prompt 精简**：去掉重复指令、合并零散要求。
- **工具/检索面收窄**：RAG 减召回文档数、限制 top-k；Agent 减少不必要中间调用轮数。
- **模型分级**：简单任务用便宜/快模型，复杂任务才上贵模型。
- **缓存复用**：命中 prompt 缓存、复用已算结果，避免重复计算。

## 常见失败点（Gotchas）
- **只估输出、漏算输入**：ReAct/Loop/Agent 多轮的成本大头在"每轮回带的上下文"，必须按"调用次数 × 上下文"算。
- **价格用死值**：模型单价常变（尤其豆包），标注"以官方实时价为准"。
- **把估算说成精确**：token 计数依赖具体模型 tokenizer，每个数字标真实值或估算。
- **只给流水账、不给优化**：核心交付是省钱方案。
- **忽略缓存/重试成本**：有证据就纳入。
- **口径混乱**：每项必须标注来源。

## 约束
- 所有数字必须标注口径（真实值 / 估算），估算要写明假设。
- 价格优先级：用户实际/套餐价 > 官方价 > 市场参考价；提示价格以官方最新为准。
- 不做无来源的精确承诺：估算仅作量级参考。
