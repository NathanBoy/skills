# 谣了个谣 · News Credibility Checker

> 分类：行业专业 ｜ 版本：v1.0.0 ｜ 链接：https://skillhub.cn/skills/user_ac54d1c1/news-credibility-checker

## 一句话简介
新闻/消息可信度判别器。当用户要求"这条新闻是真的吗 / 帮我辨别真假 / 这个说法可信吗 / 帮我评估下这条消息 / 这消息是不是谣言"等，或提供一条新闻、短视频内容、网络传言、营销号说法并要求判别其可信度时使用。从新闻传播学视角，通过信源评估、多方交叉验证、内容特征分析、证据链核查、传播学信号识别等方法论，输出多维置信度评分 + 论证过程，帮用户快速判断消息可信度。

## 核心职责
把"这条消息真假难辨"变成**可解释的置信度评估**：从新闻传播学专业视角，对消息做多维评分，输出分维度得分 + 加权总分 + 论证过程——告诉你"为什么给这个置信度、依据是什么"。**辅助用户判别，不替用户下绝对结论。**

## 核心机制：多维置信度评分
按 `METHODOLOGY.md` 对消息逐维度评估，然后运行 `credibility_score.py` 计算置信度。五个维度：

1. **信源权威性**：发布机构是否权威/专业背书；核心来源是否匿名/不知名账号（会拉低）。
2. **多方交叉验证**：至少 2 个独立信源一致才加分；仅单一来源 → 降级。
3. **内容特征**：标题党、情绪化措辞、绝对化表述、缺时间地点证据 → 减分。
4. **证据可核实性**：数据/图片/视频能否反向检索、时间线是否合理、引用是否断章取义。
5. **传播学信号**：异常爆发式扩散、水军/营销号带节奏、复制粘贴式转发 → 减分。

输出：各维度得分 + 加权总分 + 结论分级。

## 结论标签规范
| 总分 | 标签 | 含义 |
| --- | --- | --- |
| ≥ 80 | 🟢 高可信 | 多源权威、证据扎实 |
| 60-79 | 🟡 需核实 | 关键点待证实 |
| 40-59 | 🟠 疑似存疑 | 多处疑点 |
| < 40 | 🔴 疑似谣言 | 证据严重不足或矛盾 |

## 使用前请用户提供
- **消息原文 / 截图 / 链接**（至少其一）
- **来源渠道**：发布账号/平台，是权威媒体还是匿名账号
- 有则补充：传播情况、涉及的图片/视频

## 安全边界（强制）
- 本 skill 提供**判别方法论与置信度评估**，辅助用户建立媒介素养，**不充当权威裁判**。
- 对**敏感政治/社会事件**：只做中性、可解释的技术评估，**不对特定事件做绝对"真/假"定性**。
- 结论一律用**置信度/需核实/疑似存疑**等弹性口径，最终判断由用户结合多方信源做出。

## 升级路线（Roadmap）
- 图片/视频反向检索接入（自动核验媒体证据）。
- 更多元的传播信号模型（异常转发速率、账号矩阵识别）。
- 增加"跨语言/跨平台溯源"维度。
- 输出分级结果可视化（置信度仪表盘/雷达图）。
